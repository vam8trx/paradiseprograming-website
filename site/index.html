How it works

You edit it yourself

Every page has an editor behind a sign-in. Type the new words, upload the new picture, press Save, and it's live. Nobody needs a GitHub account or a developer on call.

Sign-in by email code

No passwords to forget. Members and editors sign in with a one-time code sent to their email, and you decide who can see the members area and who can edit pages.

Fast and backed up

Sites run on Cloudflare's network, so they load quickly even on rural cell service. Your pages and documents get backed up automatically.

Built for what you do

Hall bookings, burn bans, memorials, member documents, volunteer sign-ups. Each site gets the pieces that organization actually uses, not a generic template.
